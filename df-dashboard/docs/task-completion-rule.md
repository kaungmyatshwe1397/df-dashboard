# Task Completion Rule

After completing any task from `docs/frontend-plan.md`, update the plan file as follows:

1. **Timestamp** — Update the task header to include `(Completed <date> <time>)` — e.g. `(Completed 9/2/2026 12:30PM)`.
2. **Checkboxes** — Mark all "Things To Do" items with ✅.
3. **Backend Remarks** — Add a **Backend Plan Remarks** section if any mock methods, data shapes, or client-side logic will need to be replaced with Supabase calls — document what maps to which table/RLS/middleware.
4. **Summary Table** — Update the **Task Summary** table at the bottom to mark the task ✅.
5. **Consistency** — Follow existing format and tone from completed tasks (1–5) as reference.
